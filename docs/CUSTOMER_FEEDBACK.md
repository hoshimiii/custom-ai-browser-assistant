# 客户痛点与迭代验收清单

来源：2026-06-19 子 agent 以 Monica 类浏览器助手重度用户视角进行产品评审。

## P0：本轮必须解决

### 1. 页面相关问答默认读取网页内容

- 普通侧边栏发送问题时，应默认附带当前网页标题、URL 和正文内容。
- 读取失败时要明确提示，不能静默退化为普通聊天。
- 侧边栏应显示当前上下文状态：当前网页、选中区域、截图、资料库或未读取。
- 页面切换后不能误用旧上下文。

验收：用户在网页上打开侧边栏，直接输入问题即可获得基于当前网页的回答。

### 2. 交互尽量在侧边栏完成

- 移除侧边栏里的 `prompt` / `confirm` 弹窗。
- 问当前页、截图问答、资料库问答、清空历史等流程都在侧边栏内完成。
- 错误、进度、成功提示进入侧边栏消息流或状态区域。

验收：主流程不再打断阅读流，也不依赖浏览器原生弹窗。

### 3. Monica 式网页内双语翻译

- 页面翻译要自动识别正文段落、标题、列表项等文本块。
- 原文在页面原位置标记，下方插入译文。
- 不破坏输入框、按钮、导航、脚本、样式、隐藏元素、代码块等区域。
- 支持隐藏、显示、清除译文，重复翻译不重复插入。
- 长页面应分批处理并显示进度。

验收：用户能在原网页中逐段对照阅读译文。

### 4. 页面区域选择基础能力

- 提供“选择页面区域”入口。
- 鼠标悬停高亮页面元素，点击后把该区域作为当前上下文。
- 侧边栏显示已选区域摘要，并允许取消选择回到整页模式。
- 后续总结、问答、翻译优先基于选中区域。

验收：复杂页面中用户可以把助手限定到文章正文、评论区或某个内容块。

### 5. 截图问答侧边栏化

- 点击截图问答后自动截取当前可视页面。
- 侧边栏显示截图预览。
- 用户在同一侧边栏输入问题并发送，支持默认分析。
- 支持重新截图和失败提示。

验收：用户能确认要发送的截图，并直接在侧边栏完成视觉问答。

## P1：高优先级

### 6. 快捷键提示产品化

- 设置页展示默认快捷键。
- 侧边栏设置入口附近展示快捷键提示。
- 提供跳转或说明：可在 `chrome://extensions/shortcuts` 修改快捷键。

### 7. 页面上下文状态可见

- 输入区附近展示当前模式。
- 页面读取失败时明确展示“未读取网页”。
- 基于网页/区域/截图/资料库回答时在消息中标明来源。

### 8. 翻译结果可控

- 提供隐藏译文、显示译文、清除译文控制。
- 翻译失败不污染 DOM。
- 重复翻译不会插入多份译文。

### 9. 长页面进度

- 显示读取、分段、翻译第 N 段等进度。
- 对超长内容说明截断或分批策略。

## P2：后续优化

- 选中文本工具栏与侧边栏状态联动。
- 搜索页助手避免侵入搜索结果布局。
- 设置页逐步升级为完整控制台，包含翻译样式、默认上下文模式、截图行为等开关。

## 本轮一句话验收标准

用户打开任意网页后，只靠侧边栏就能问当前页、翻译正文、选择区域追问、截图提问，并且不用复制粘贴网页内容、不被浏览器弹窗打断。
